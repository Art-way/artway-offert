# Artway – kampanjsida för flytthjälp

صفحة حملة سويدية مستقلة، مبنية بملفات HTML/CSS/JavaScript مباشرة، مع صور الشركة الحقيقية ونفس نموذج Elfsight الأصلي. ملفات الموقع القابلة للنشر موجودة في `dist/`. لا توجد خطوة build أو مكتبات واجهة أو مفاتيح API مطلوبة.

مستودع المشروع: [Art-way/artway-offert](https://github.com/Art-way/artway-offert). تحديثات هذا المشروع تُرفع إلى GitHub. بناءً على طلب المالك، لا تنشره أو تحدّثه على GPT Sites.

## المعاينة المحلية

من هذا المجلد:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

ثم افتح `http://127.0.0.1:4173/`.

## الفورم

- معرّف Elfsight: `47186b70-4c2e-4d1e-9fc1-4ada8aabc106`.
- يتم تحميل السكربت الرسمي عند ظهور مساحة الفورم أو ضغط زر طلب العرض. لا يتم إعادة إنشاء الفورم أو تغيير وجهة استقبال الطلبات.
- التكامل الأصلي يتضمن البريد وGoogle Sheets، حسب إعدادات Elfsight العامة وقت الفحص.
- صفحة النجاح الأصلية: `https://artway.se/tack-for-din-forfragan/`.
- تم التحقق من التحقق من الحقول المطلوبة، والتنقل بين الخطوات الأربع، وزر العودة؛ لم يتم إرسال طلب تجريبي أو بيانات عملاء.
- يوجد رابط احتياطي للفورم الأصلي ورقم هاتف واضح إذا تعذر تحميل المزود.

## التنفيذ والفحص

دعوة إجراء واضحة، فورم دون التزام، أزرار اتصال وطلب عرض على الموبايل، صور WebP متجاوبة، أبعاد صور محجوزة، تحميل مؤجل للصور والفورم، خط محلي، أسئلة شائعة قابلة للاستخدام بلوحة المفاتيح، واحترام تقليل الحركة.

القياس محلي، وقد أبلغ Lighthouse عن بطء معالج الجهاز. لا تمثل هذه النتائج قياساً ميدانياً لـ INP أو ضماناً لمعدل التحويل. في الموبايل لا توجد طلبات Elfsight قبل ظهور الفورم. بعد تحميله، تبقى بعض ملاحظات الوصول والتباين وملفات الطرف الثالث من النموذج الأصلي نفسه؛ لم يتم تغيير سلوك المزود. التقارير الكاملة ولقطات Playwright موجودة محلياً في `output/` ومستثناة من نشر المصدر.

الصفحة مضبوطة على `noindex` للمعاينة؛ لذلك نتيجة SEO في Lighthouse هي 63. يمكن استضافة محتويات `dist/` مباشرة على استضافة ملفات ثابتة. لا توجد حاجة لإعدادات GPT Sites أو أي اعتماد عليها. لا يتضمن رفع الملفات إلى GitHub تفعيل استضافة أو ربط نطاق.

## القياس الإعلاني

لا تساوي نقرة زر طلب عرض تحويلاً مكتملًا. إن كانت `dataLayer` موجودة، ترسل الصفحة حدث نية فقط باسم `artway_quote_cta` مع موضع الزر. لا تضيف الصفحة Google Ads أو Meta Pixel تلقائياً، ولا تسجل طلباً ناجحاً دون إرسال فعلي. يجب التحقق من تتبع اكتمال الطلب على صفحة الشكر ضمن إعداد إطلاق الحملة.
